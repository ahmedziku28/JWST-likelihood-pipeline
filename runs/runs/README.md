# MCMC Run Infrastructure

This directory contains **112 predetermined MCMC runs** for the exotic
transient dark-energy campaign. Generated by `generate_all_runs.py`.

## Folder hierarchy

```
runs/
├── exotic/
│   ├── full/  {fixed,vbeta,vshmr}/  <run_name>/  ({.yaml, .sh, outputs/})
│   └── restr/ {fixed,vbeta,vshmr}/  <run_name>/
├── lcdm/
│   ├── full/  {fixed,vbeta,vshmr}/  <run_name>/
│   └── restr/ {fixed,vbeta,vshmr}/  <run_name>/
└── non_uvlf/
    └── <run_name>/                    ({.yaml, .sh, outputs/})
```

## Run-name convention

`{model}_{data}_{shmr}_{zcut}` for UVLF runs (108), `{model}_{data}` for
non-UVLF runs (4).

| Field   | Values |
|---------|--------|
| `model` | `exo` (exotic DE active), `lcdm` (exotic DE disabled) |
| `data`  | `ceers`, `primer`, `uvlf`, `ceers_bg`, `primer_bg`, `uvlf_bg`, `ceers_bg_cmb`, `primer_bg_cmb`, `uvlf_bg_cmb`, `bg`, `bg_cmb` |
| `shmr`  | `fixed`, `vbeta`, `vshmr` |
| `zcut`  | `full` (z >= 9.0/8.9), `restr` (z >= 10.0/10.9) |

## Submitting runs

**Recommended workflow** (via `run_manager.py`):
```
python run_manager.py test                      # submit the 6 test runs
python run_manager.py status                    # monitor progress
# once all 6 are CONVERGED:
python run_manager.py auto 8                    # daemon: keep 8 jobs active
```
Converged runs are automatically skipped by `launch` and `auto`.

**Manual single-run submission**:
```
cd runs/<path>/<run_name> && sbatch <run_name>.sh
```

## Files

- `all_runs.csv` — single source of truth for downstream analysis (run name,
  flags, parameter count, folder path).
- `run_manager.log` — created by `run_manager.py auto` when active.

## Diagnostics

```
python run_manager.py doctor <run_name>         # diagnose a STALLED/FAILED run
python run_manager.py resubmit <run_name>       # resubmit a STALLED run
python run_manager.py resubmit --all-stalled    # resubmit all STALLED runs
```
